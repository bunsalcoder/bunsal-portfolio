# Bunsal — Portfolio

Modern personal portfolio for a Full-Stack Developer.

## Stack

- React + TypeScript
- Vite
- Tailwind CSS
- Motion
- Font Awesome

## Getting started

Use Node 20+:

```bash
nvm use
npm install
npm run dev
```

## Scripts

- `npm run dev` — local development
- `npm run build` — production build
- `npm run preview` — preview production build

## Content

Update portfolio content in:

- `src/data/site.ts`
- `src/data/experience.ts`
- `src/data/projects.ts`
- `src/data/skills.ts`

Project screenshots can be added under each project's `details.screenshots` array.
